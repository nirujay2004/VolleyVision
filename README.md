# 🏐 VolleyVision

VolleyVision is a Computer Vision based volleyball analysis prototype.

The system processes volleyball match footage and uses YOLO for player detection and ByteTrack for multi-object tracking.

## Features

- 🏐 Volleyball video processing
- 👤 Player detection using YOLO
- 🔢 Persistent player tracking using ByteTrack
- 🎥 Video-based Computer Vision pipeline
- 📊 Tactical visualization prototype
- 🖥️ OpenCV-based visualization

## Tech Stack

- Python
- OpenCV
- Ultralytics YOLO
- ByteTrack
- NumPy
- Pandas
